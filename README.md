# دواوين الوفرة

دليل مجتمعي لأهالي مدينة الوفرة السكنية في الكويت: المناسبات، الدواوين، الإعلانات، الخدمات، المطاعم، الكافيهات، الصيدليات، المساجد، الصالونات، والعقار.
الزوار يتصفحون بلا تسجيل. المشرف يدخل برمز سري، والخادم وحده يتحقق منه.

## البنية

```
المتصفح (index.html + app.js)
   │  GET  /api/public        بيانات عامة مفلترة (بلا أرقام صفوف وبلا المنتهي)
   │  POST /api/login         ← يضع Cookie جلسة HttpOnly; Secure; SameSite=Strict
   │  POST /api/admin         ← كل عمليات الإدارة، بالجلسة فقط
   ▼
Cloudflare Pages Functions (functions/)
   │  يضيف GATEWAY_SECRET وعنوان IP الذي يضعه Cloudflare (CF-Connecting-IP)
   ▼
Google Apps Script (apps-script/Code.gs) ── Google Sheets (البيانات) + Drive (الصور)
```

| المسار | الوصف |
| --- | --- |
| `index.html` | الصفحة (HTML وCSS) |
| `app.js` | منطق الواجهة كاملاً |
| `privacy.html`، `terms.html` | سياسة الخصوصية وشروط الاستخدام |
| `functions/api/[[route]].js` | البوابة: login، logout، session، admin، public |
| `functions/_middleware.js` | ترويسات الأمان ومعرّفات الأخطاء لكل استجابات الدوال |
| `functions/_lib/` | الاتصال بـ Apps Script، والـ Cookies، وفحص CSRF |
| `functions/e,d,a/[id].js` | صفحات معاينة روابط المشاركة في واتساب |
| `functions/img.js` | وسيط صور Drive للسجلات المنشورة فقط |
| `_headers` | CSP وبقية ترويسات الأمان للملفات الثابتة |
| `apps-script/Code.gs` | الخادم |
| `tests/` | اختبارات الخادم والبوابة والمتصفح |

لا توجد خطوة بناء: المستودع يُنشر كما هو، والإعدادات والأسرار من متغيرات Cloudflare وخصائص Apps Script.

## الأمان

- **الجلسات:**
  - الرمز السري يُرسَل مرة واحدة عند الدخول، ولا يُحفظ في المتصفح.
  - الجلسة Cookie بالخصائص `HttpOnly; Secure; SameSite=Strict`، ولا تقرؤها أي شيفرة في الصفحة.
  - الخادم يحفظ ملخّص SHA-256 لرمز الجلسة فقط.
  - تنتهي الجلسة بعد 12 ساعة بلا استخدام، و7 أيام حداً أقصى.
  - تغيير الرمز يلغي كل الجلسات.
- **الحد من المحاولات:**
  - لكل عنوان IP على حدة، والعدّ تحت `LockService`.
  - بعد 5 محاولات خاطئة يبدأ انتظار يتضاعف حتى 30 دقيقة، ولا يتأثر المشرف من عنوان آخر.
  - سقف عام يبطئ الرد ويسجّل تنبيهاً، ولا يغلق الدخول.
- **CSRF:** طلبات الكتابة تشترط الترويسة `X-Wafra: 1` وأن يكون `Origin` و`Sec-Fetch-Site` من الموقع نفسه.
- **الاتصال المباشر بـ Apps Script:** لا يقبل أي عملية إدارية بدون `GATEWAY_SECRET`. الطريقة القديمة (الرمز مع كل طلب) انتقالية، وتُغلق بالخاصية `LEGACY_PIN=off`.
- **التحقق في الخادم:**
  - الأقسام والأوراق والأعمدة معتمدة في الخادم (`SECTIONS`)، والمتصفح لا يحدد أسماء الأوراق.
  - لكل حقل نوع وطول. الهواتف تقبل الأرقام العربية و`+`. التواريخ حقيقية ومرتّبة. الروابط `https` فقط.
  - القيم القديمة غير المعدّلة تُقبل كما هي.
- **حقن الصيغ:** القيم التي تبدأ بـ `=` أو `@` (و`+` أو `-` لغير الأرقام) تُحفظ نصاً.
- **الرفع:**
  - المسموح JPEG وPNG وWebP حتى 5 ميغابايت، وMP4 حتى 25 ميغابايت، ويُفحص توقيع الملف نفسه.
  - الملف يبقى خاصاً في مجلد «معلّق» حتى يُحفظ سجله.
  - حذف السجل يلغي المشاركة العامة لصوره، إلا الصور التي يستخدمها سجل آخر.
- **الخصوصية:**
  - `/api/public` يعيد الأعمدة المعتمدة فقط، بلا أرقام صفوف ولا أوراق إدارية ولا محتوى منتهٍ.
  - المناسبات تبقى 14 يوماً بعد نهايتها كما يعرضها التطبيق.
- **الأخطاء:** الزائر يرى معرّفاً مثل `E-7K2Q1A` فقط، والتفاصيل في ورقة «سجل الأخطاء» أو سجل Cloudflare.
- **السجل:**
  - كل عملية تُسجَّل مع المشرف والجلسة والقيمة السابقة واللاحقة.
  - إذا فشل التسجيل يُحفظ السطر للتسوية، ويُبلَّغ المشرف.

## الاختبار

المتطلبات: Node.js 20 أو أحدث، وPlaywright 1.63.0 مع Chromium.

```bash
npm install            # أو: npm install playwright@1.63.0
npx playwright install chromium
npm test
```

| الملف | المحتوى |
| --- | --- |
| `tests/helpers/gas-mock.js` | محاكاة كاملة لخدمات Apps Script (Sheets وDrive وProperties وCache وLock وساعة قابلة للتقديم) |
| `tests/server.test.js` | اختبارات Unit للخادم |
| `tests/gateway.test.js` | اختبارات Integration: كود الدوال الحقيقي مع الخادم المحاكى |
| `tests/e2e.test.js` | Playwright: الصفحة الحقيقية مع CSP، والدوال، والخادم المحاكى، ولا شيء يصل إلى Google |

## النشر

### Cloudflare Pages

Settings → Variables and Secrets، كل بيئة على حدة:

- `GAS_URL`: رابط `/exec`. المعاينة تشير إلى جدول الاختبار، والإنتاج إلى الجدول الحقيقي.
- `GATEWAY_SECRET` (نوع Secret): 32 خانة عشوائية على الأقل، وقيمة مختلفة لكل بيئة.

### Apps Script

1. الصق `apps-script/Code.gs`.
2. أضف الخصائص `GATEWAY_SECRET` و`PIN` و`GEMINI_KEY` في Script properties.
3. شغّل `checkSetup` للتأكد من أن الإعداد مكتمل.
4. انشر عبر Deploy ← Manage deployments ← تعديل ← New version، فيبقى رابط `/exec` كما هو.

### الترتيب في الإنتاج

1. نسخة احتياطية من الجدول.
2. نشر Apps Script الجديد (يقبل الطريقتين مؤقتاً).
3. متغيرات Production في Cloudflare.
4. دمج الفرع في `main`.
5. تجربة الدخول والحفظ.
6. ضبط `LEGACY_PIN=off`، ثم تغيير الرمز من لوحة «الأمان».
7. بعد أسبوع: إلغاء «Publish to web» لملفات CSV.

### التراجع

- **الموقع:** Cloudflare Pages ← Deployments ← Rollback، أو فرع `backup-before-stage1`.
- **Apps Script:** اختيار الإصدار السابق من Manage deployments.
- **الخصائص:** بقاء `PIN` القديم يجعل الكود القديم يعمل مباشرة.

## تخزين البيانات

ورقة لكل قسم في Google Sheets، وأوراق إدارية لا تُقرأ للعامة: «المحذوفات» و«سجل العمليات» و«سجل الأخطاء». التفاصيل في `docs/DATABASE.md`. النسخ الاحتياطي اليومي يحتفظ بآخر 30 نسخة من الجدول، ويُنظّف في الوقت نفسه الملفات المعلّقة القديمة والجلسات المنتهية.
