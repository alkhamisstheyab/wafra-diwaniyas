# بنية قاعدة البيانات

قاعدة البيانات جدول Google Sheets واحد. كل قسم ورقة مستقلة، والصف الأول عناوين الأعمدة، وكل القيم تُحفظ نصاً (`setNumberFormat('@')`) والتواريخ بصيغة `YYYY-MM-DD`.
لا يوجد بعد معرّف ثابت للسجل (المرحلة 2): يُعرَّف السجل برقم صفّه، ويتحقق الخادم قبل التعديل أو الحذف من أن قيمة «عمود التحقق» لم تتغير. الأعمدة المعتمدة لكل قسم محددة في الخادم (`SECTIONS` في `apps-script/Code.gs`)، والمتصفح لا يستطيع إنشاء ورقة أو تسميتها.

## أوراق الإدارة (لا تُقرأ للعامة)

| الورقة | الأعمدة | من يكتب فيها |
| --- | --- | --- |
| المحذوفات | وقت الحذف، مفتاح القسم، القسم، رقم الصف الأصلي، السجل، البيانات (JSON للصف كاملاً) | إجراء `delete`؛ وإجراء `restore` يعيد الصف لآخر ورقته ويحذفه من هنا |

## Script Properties

| المفتاح | المحتوى |
| --- | --- |
| `GATEWAY_SECRET` | مفتاح البوابة بين Cloudflare وApps Script (سرّي) |
| `PIN` | رمز الإدارة الأولي نصاً؛ يُحذف بعد أول تغيير |
| `PIN_HASH`، `PIN_SALT` | ملخّص رمز الإدارة |
| `SESSION_EPOCH`، `sess_<hash>` | رقم جيل الجلسات، والجلسات النشطة (ملخّص الرمز فقط) |
| `LEGACY_PIN` | `off` يغلق الطريقة القديمة |
| `pendinglog_*` | أسطر سجل بانتظار التسوية |
| `GEMINI_KEY` | مفتاح قراءة الصور (سرّي) |
| `sheet_<key>` | اسم ورقة كل قسم أُنشئ تلقائياً |
| `stat_views`، `stat_devices`، `stat_day_YYYY-MM-DD` | عدّادات الزيارات |

## الملفات المرفوعة

مجلد Google Drive «صور دواوين الوفرة». الملف الجديد يُرفع خاصاً إلى المجلد الفرعي «معلّق»، ولا يُنقل إلى المجلد الرئيسي ويُشارَك «لأي شخص لديه الرابط» إلا عند حفظ سجله. حذف السجل يلغي المشاركة ما لم يستخدم الملف سجل آخر. الملفات المعلّقة الأقدم من يومين تُنقل إلى سلة Drive.

## النسخ الاحتياطي

الدالة `dailyBackup` (مؤقّت يومي الساعة 3 فجراً بتوقيت الكويت، يُفعَّل بـ `setupDailyBackup`) تنسخ الجدول كاملاً إلى مجلد «نسخ دواوين الوفرة الاحتياطية» وتحتفظ بآخر 30 نسخة، وتنظّف الملفات المعلّقة القديمة والجلسات المنتهية. نسخ ملفات Drive نفسها يأتي في المرحلة 2.
